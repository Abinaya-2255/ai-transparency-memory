Five decisions shaped the experience

Progressive disclosure

Keep the conversation simple. Reveal deeper context only when requested.

Contextual explanation

Explain the specific answer rather than forcing users into generic AI settings.

Actionable transparency

Let users change the context instead of only reading about it.

Different types of context

Verified information, memory, assumption and AI interpretation should not look identical.

User agency

Give users control at both the individual response level and the long term memory level.

I wanted to test whether the transparency model worked as an interaction rather than only as a visual concept. The prototype uses controlled demo scenarios to simulate dynamic AI responses, memory states, assumptions and transparency metadata. It is a functional concept prototype, not a production AI system.

What is actually functional

Conversation Multiple demo scenarios

Four controlled scenarios: internship decision, recruiter questions, salary and portfolio. Each has its own sources, memories and assumptions.

Transparency Contextual explanation drawer

Verified, Memory used and Explain response each open the same drawer on the relevant section.

Memory Inspect, edit, pause, archive, delete

Search, filter, add and pin too. Deleting asks for confirmation.

Response control Exclude a memory from one answer

The answer regenerates and a note says what changed.

Assumptions Edit and update the response

Confirm it or change it. The recommendation rewrites using your correction.

Persistence Demo state persists

Saved in the browser with localStorage. Reset demo restores the original state.

The goal isn't to make AI explain everything.

It's to give people enough understanding to stay in control.
